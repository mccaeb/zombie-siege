# Graveyard Shift

A 3D top-down zombie survival shooter that runs in the browser. Hold the cemetery through endless waves and nights that get longer and nastier. Keep every gun you find.

```
npm install
npm run dev      # play locally
npm run build    # single-file build in dist/
```

Controls: WASD to move, mouse to aim, click to shoot, R to reload, 1–4 / Q / wheel to switch guns, P to pause. On touch, use twin sticks (left moves, right aims and fires).

Balance lives in `src/config.js`.
